## Featured Case Study

### Tuah Kopi — Business Operations System

A connected business operations system designed for a multi-outlet coffee business.

The project consists of a mobile application for outlet operations and a responsive owner dashboard for centralized monitoring and management.

### Core Areas

- Sales transaction management
- Multi-outlet architecture
- Inventory and stock tracking
- Expense management
- Free meal records
- Purchase Order workflow
- Centralized product pricing
- Event-based pricing
- Sales analytics
- Outlet performance monitoring
- Firebase Authentication
- Firestore data integration

The full source code of the business system is private. The portfolio contains a detailed public case study explaining the system, workflows, and engineering decisions without exposing the private application source code.
